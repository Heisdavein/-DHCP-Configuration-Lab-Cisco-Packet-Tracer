# 4. Edge Router: DHCP Client and LAN DHCP Server
 
The Edge-Router has two DHCP roles at once:
 
| Interface | Role | Behaviour |
|---|---|---|
| WAN (FastEthernet 0/0) | DHCP client | Requests its address from the ISP-Router. Expected: 200.1.1.2. |
| LAN (FastEthernet 0/1) | DHCP server | Leases addresses to the PCs from LAN-POOL |
 
The same router is a client upstream and a server downstream, as a home or small-office router is with an ISP. Full configuration: [`configs/edge-router.cfg`](../configs/edge-router.cfg).
 
## 4.1 WAN interface as DHCP client
 
```
Edge-Router(config)# interface fastEthernet 0/0
Edge-Router(config-if)# ip address dhcp
Edge-Router(config-if)# no shutdown
```
 
`ip address dhcp` makes the interface run the DHCP client exchange with the ISP-Router instead of using a manual address. With the ISP-Router configured and its interface enabled, the Edge-Router receives 200.1.1.2.
 
## 4.2 LAN interface
 
```
Edge-Router(config)# interface fastEthernet 0/1
Edge-Router(config-if)# ip address 192.168.1.1 255.255.255.0
Edge-Router(config-if)# no shutdown
```
 
The LAN address is static because the PCs need a fixed default gateway.
 
## 4.3 LAN DHCP service
 
```
Edge-Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10
Edge-Router(config)# ip dhcp pool LAN-POOL
Edge-Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Edge-Router(dhcp-config)# default-router 192.168.1.1
Edge-Router(dhcp-config)# dns-server 8.8.8.8
```
 
| Setting | Value | Reason |
|---|---|---|
| Excluded range | 192.168.1.1 to 192.168.1.10 | Router address plus space for fixed infrastructure |
| Network | 192.168.1.0/24 | LAN subnet |
| Default router | 192.168.1.1 | Edge-Router LAN interface |
| DNS server | 8.8.8.8 | Name resolution for clients |
 
Clients receive addresses starting at 192.168.1.11: PC1 gets 192.168.1.11 and PC2 gets 192.168.1.12, with mask 255.255.255.0, gateway 192.168.1.1 and DNS 8.8.8.8.
 
## 4.4 Save
 
```
Edge-Router(config)# end
Edge-Router# write memory
```
 
## 4.5 Configuration flow
 
1. ISP-Router creates 200.1.1.0/24 and provides DHCP.
2. Edge-Router WAN requests an address and receives 200.1.1.2.
3. Edge-Router LAN uses 192.168.1.1 as the gateway for the local network.
4. Edge-Router leases 192.168.1.11 and 192.168.1.12 to PC1 and PC2.
5. `show` commands and ping tests verify each step ([Verification](05-verification.md)).
